# 2D Video Game Development Course Project

This repository contains the code and resources from the 2D Video Game Development Project with Unity course taught at the University of La Laguna (ULL). The course aims to teach students the fundamentals of video game development using the Unity engine, focusing on creating 2D games.

## The Lonely King

The game developed during this course is titled "The Lonely King". It is a 2D platformer where players control a king who embarks on a journey through various levels filled with obstacles and enemies. The objective is to reach the end of each level while collecting items and avoiding hazards.

### Game Features

- **Platforming Mechanics**: Jumping, running, and navigating through different terrains.
- **Enemy Encounters**: Various enemies that challenge the player's skills.
- **Collectibles**: Items scattered throughout levels that players can collect for points or power-ups.
- **Level Design**: Multiple levels with increasing difficulty and unique themes.

### Levels

The game consists of 3 levels, each with its own design and challenges:

1. **Level 1**: A basic introduction to the game mechanics with simple obstacles and enemies.
2. **Level 2**: Increased difficulty with more complex platforming sections and tougher enemies.
3. **Level 3**: The final level featuring challenging terrain and a boss fight.
